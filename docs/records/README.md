# Records of designs

Each file here records one design: what was proposed, the spikes and reviews it had, and what the owner or an agent
decided, with its status at its head. A record is history, not a rule: where it and the code differ, the code, the
guide, [`invariants.md`](../invariants.md) and [`premises.md`](../premises.md) rule. What was rejected, and what would
reopen it, is in [`rejected.md`](../rejected.md).

From 26 November 2026 on, a record is written only for a decision whose reasons do not fit the body of a commit
("Deciding" in [`AGENTS.md`](../../AGENTS.md)), in a page at most: most decisions need none. The records written before
stay as they are.
