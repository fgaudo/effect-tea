# Glossary

## In short

The words the guide uses, each in a line, with the page that defines it. This page is a summary: the page it links
rules where a line here says less.

## A program and its pieces

| Word        | What it is                                                                                                                                                                                                               | Defined in                                        |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------- |
| **Program** | A plain object: `init`, `update`, `makeModel`, `subscriptions`, `listen` when it has keys, `runCommand` when it has commands, `external` when it has external messages, and `output` when its parent reads a value of it | [anatomy of a program](./anatomy-of-a-program.md) |
| **State**   | What the program knows: any value, replaced and never mutated                                                                                                                                                            | [anatomy of a program](./anatomy-of-a-program.md) |
| **Message** | What `update` is given: a click the model holds, a command's answer, what a subscription sends                                                                                                                           | [update](./update.md)                             |
| **Step**    | What `update` returns for a message it accepts: `{ state, commands?, events?, tell? }`                                                                                                                                   | [update](./update.md)                             |
| **Flags**   | What a program starts from, when it cannot start the same way every time                                                                                                                                                 | [anatomy of a program](./anatomy-of-a-program.md) |

## What the user sees

| Word                    | What it is                                                                                                                                                                        | Defined in                                                                                                          |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **Model**               | What `makeModel(state)` makes for the view: what it shows, and the messages its controls send                                                                                     | [model](./model.md)                                                                                                 |
| **View**                | A function `(model, dispatch) => Node` that draws the model. It is not part of the program                                                                                        | [view](./view.md)                                                                                                   |
| **Dispatch**            | What a view sends a message with: a function that applies the message before it returns, and returns nothing                                                                      | [view](./view.md)                                                                                                   |
| **`App`**               | What a renderer reads: `{ model, subscribe, dispatch, die }`, the model of the current state and a notice of each new state                                                       | [running](./running.md#rules)                                                                                       |
| **Renderer**            | What draws the model of an `App`. What it draws beside it is its bridge's to say                                                                                                  | [view](./view.md)                                                                                                   |
| **Memoized** (view)     | A view that the renderer draws again only when one of the values it is given is a new one, as with snabbdom's `thunk`                                                             | [running](./running.md), [composition](./composition.md#childrens-views)                                            |
| **Handler** (of a view) | A callback of the renderer that sends a message the model holds: `() => dispatch(model.save)`                                                                                     | [writing a bridge](./writing-a-bridge.md#handlers)                                                                  |
| **Controlled element**  | An element with a value of its own, as a text field, drawn with the value its model holds, whose handler sends the message that its model holds for it, filled with what it holds | [writing a bridge](./writing-a-bridge.md#a-controlled-element), [what an element gives](./what-an-element-gives.md) |
| **Bridge**              | What connects the library to a renderer: it draws the model, sends messages, and draws controlled elements                                                                        | [writing a bridge](./writing-a-bridge.md)                                                                           |

## Effects

| Word                       | What it is                                                                                                                                                                                          | Defined in                                                                   |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| **Command**                | Data that says what `update` decided. `runCommand` alone turns it into an Effect                                                                                                                    | [commands](./commands.md)                                                    |
| **Execution**              | The Effect a command becomes: it cannot fail, and may produce one message back                                                                                                                      | [commands](./commands.md)                                                    |
| **Subscription**           | What the program listens to, or work it keeps going, while its state wants it: a `Channel` of messages, made from its key by `listen`                                                               | [subscriptions](./subscriptions.md)                                          |
| **Key**                    | Data that `subscriptions(state)` lists for a subscription, and that `listen` makes the subscription from. Keys are compared by value: a new key starts its subscription, and a missing key stops it | [subscriptions](./subscriptions.md)                                          |
| **Services**               | The Effect services that `runCommand` and `listen` use. They are inferred from them, never named (`program` refuses `commandServices` and `subscriptionServices`), and provided around `run`        | [anatomy of a program](./anatomy-of-a-program.md), [commands](./commands.md) |
| **Handler** (of a service) | The code that does a service's operations, such as the save. The layer provided around `run` holds it                                                                                               | [commands](./commands.md#services-handlers-and-events)                       |
| **Run**                    | The program's effects, running: the `run` that `start(program, options?)` gives, until it is interrupted or a defect ends it                                                                        | [running](./running.md)                                                      |

## Messages that do not fit

| Word                  | What it is                                                                                                                                                                                       | Defined in                                                                                       |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| **Reject**            | What `update` returns for a message that may arrive, and does not apply in the state. The run ignores it                                                                                         | [rejections and defects](./rejections-and-defects.md)                                            |
| **Ignored**           | What a message that `update` rejects is, where its rejection fails nothing: the state stays as it was. `onIgnored` hears each one in a run, and `simulate` and `rehearse` list them in `ignored` | [rejections and defects](./rejections-and-defects.md), [testing tools](./testing-tools.md#rules) |
| **Defect**            | What a synchronous function of the program throws, as `update` throws `defect(reason)` on a message that cannot arrive: a bug. The run dies                                                      | [rejections and defects](./rejections-and-defects.md)                                            |
| **`InvariantDefect`** | What `defect(reason)` throws, holding the reason. A crash report can tell it from any other error                                                                                                | [rejections and defects](./rejections-and-defects.md)                                            |
| **`ProgramDefect`**   | What the run dies with on a defect. Its `where` says where the defect happened, and its `cause` is the defect itself                                                                             | [running](./running.md#when-a-defect-happens)                                                    |

## A program made of programs

| Word                         | What it is                                                                                                                                                                                               | Defined in                                                                                         |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **Composition**              | How a parent declares its children, and, from its own state, when each child is there                                                                                                                    | [composition](./composition.md)                                                                    |
| **Child**                    | Any program, declared by a parent, and kept by the library. `child` declares one always there, and `childWhen` one that may not be. A child by id is one of many, as the rows of a list                  | [composition](./composition.md)                                                                    |
| **Instance**                 | One start of a child, with a number of its own. A child started again is another instance                                                                                                                | [what the library derives](./composition.md#what-the-library-derives)                              |
| **`key`** (of a child alone) | A value from the parent's state, `child(program, { key })`. Where `key` gives another value, by `Equal`, the child starts again. A child with flags has no `key` beside them: other flags start it again | [when a child is there](./composition.md#when-a-child-is-there)                                    |
| **By id**                    | One child for each row, as the rows of a list. `childById` declares them                                                                                                                                 | [composition](./composition.md#children-by-id)                                                     |
| **Event**                    | What a child raises to ask its parent for something. The parent handles it in `onEvent`                                                                                                                  | [events and external messages](./events-and-external-messages.md)                                  |
| **Handler** (of `onEvent`)   | The function of `onEvent` for one child's events: `(event, children) => (state) => step`, and `(id, event, children) => (state) => step` for children by id. Its type has no `reject`                    | [events and external messages](./events-and-external-messages.md)                                  |
| **External message**         | What a parent may tell a child, in the `tell` of a step or of the child's declaration. The child answers it in `external`, in every state                                                                | [events and external messages](./events-and-external-messages.md)                                  |
| **Output**                   | What a child declares of its state for its parent to read, as whether a stopwatch runs                                                                                                                   | [outputs](./events-and-external-messages.md#outputs)                                               |
| **`CompositionDefect`**      | The defect of a broken composition, such as an external message to a child that is not there                                                                                                             | [composition](./composition.md), [events and external messages](./events-and-external-messages.md) |

## In a test

| Word           | What it is                                                                                                                                               | Defined in                                             |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| **Reader**     | A function of the test's own, from a model to the messages the model holds                                                                               | [testing](./testing.md#the-reader)                     |
| **Candidates** | The messages a user could ask for, which a test lists for `dispatchViolations`                                                                           | [testing tools](./testing-tools.md#dispatchviolations) |
| **Withheld**   | The candidates a model leaves out on purpose                                                                                                             | [testing tools](./testing-tools.md#dispatchviolations) |
| **Inert**      | The messages a model holds on purpose though their step does nothing                                                                                     | [testing tools](./testing-tools.md#dispatchviolations) |
| **Scenario**   | What a user does, played by a test: by `rehearse` without running the program, and by `drive` on the running program                                     | [testing tools](./testing-tools.md#rehearse)           |
| **Rehearsal**  | What `rehearse` gives the scenario to act with, such as `send`, `run` and `hear`. Its `run` runs a pending command: it is not the run that `start` gives | [testing tools](./testing-tools.md#rehearse)           |
